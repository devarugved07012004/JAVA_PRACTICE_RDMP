# Timeline Estimates — 1 Hour / Day

Estimates assume **~1 hour/day, 7 days/week effective** (including Day 7 review).  
**Hours ≈ weeks × 7.** Ranges reflect depth and prior programming experience.

Use the **low end** if concepts stick quickly; use the **high end** if you are new to programming or need more drills. Stay until the phase gate passes — do not cut the checklist short to hit a date.

## How to adjust

| Signal | Action |
|--------|--------|
| Checklist ≥90% a week early | Start phase project early (still Day-6 heavy) |
| Stuck on same topic > high-end weeks | Shrink scope; finish a thinner vertical slice; note gap for post-capstone revisit |
| Missed many days | Extend calendar; do not compress gates |
| Prior Java experience | Trim 01–04 toward low end; keep 05–06 honest |
