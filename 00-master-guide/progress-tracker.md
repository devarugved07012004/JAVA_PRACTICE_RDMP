# Progress Tracker

Copy-ready weekly log for the Java Full Stack Mastery Roadmap (~72–83 weeks). Be honest — inflated checkmarks slow you down at the next gate.

**How to use**

1. Each Day 7, fill one row for the week just finished.
2. Hours = actual coding/learning time (target ~7).
3. Project % = rough percent of the *current* phase project or capstone (0 if still on pure topic drills).
4. Confidence 1–5: 1 = lost, 3 = can follow along, 5 = could teach the week’s material.
5. If you prefer a spreadsheet, duplicate the column headers there; keep the same fields.

---

## Column definitions

| Column | Meaning |
|--------|---------|
| Week # | Sequential week of your journey (1…80+) |
| Topics | Topic IDs touched (e.g. `01`, `01-02`, `P1-proj`) |
| Hours logged | Integer or decimal hours this week |
| Exercises done | Short list or count (e.g. `5/7` or `DAO+tx`) |
| Project % | 0–100 for active phase project / capstone |
| Blockers | What stopped you (empty if none) |
| Next week focus | One clear outcome |
| Confidence | 1–5 |
