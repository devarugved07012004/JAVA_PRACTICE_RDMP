# Java Full Stack Mastery Roadmap

Practical, project-based path from Java fundamentals to enterprise full stack — **learning, building, and mastering only**. No interview, placement, resume, or job-application content.

**Cadence:** 1 hour/day · ~17–19 months · ~504–581 total hours  
**Approach:** Concepts → exercises → mini-projects → phase projects → capstone

**Mini-projects:** Full build guides live under [mini-projects/README.md](mini-projects/README.md) (linked from each topic’s §6).

---

## How to use this roadmap

1. Read [Learning Path](00-master-guide/learning-path.md) and [Daily Schedule](00-master-guide/daily-schedule.md).
2. Follow topics **in order** (Steps 01 → 21). Do not skip phase gates.
3. Each day open that topic’s **§4**: use the day’s **Learn** links (10 min) → **Practice** (35 min) → tick the checkboxes.
4. When a topic’s §6 mini-projects are due, follow the matching guide in [mini-projects/](mini-projects/README.md).
5. Log progress weekly in [Progress Tracker](00-master-guide/progress-tracker.md).
6. Advance when a topic’s mastery checklist is ≥90% and the phase project runs end-to-end.

## Rules of mastery

- Build every day; reading alone does not count as progress.
- Finish the phase project before starting the next phase.
- Prefer official docs over random tutorials.
- When stuck >30 minutes, write the blocker in the tracker and try a smaller slice tomorrow.
